# Custom-MTWL-Phantom
Dieses GitHub enthält alle in dieser Arbeit verwendeten Python Codes.
Hierbei ist es wichtig zu erwähnen das zur Strukturierung der Codes und zum erstellen der alternativen Pylinac-Version künstliche Intelligenz (KI) zur Hilfe verwendet wurde.
Bei der verwendeten KI handelt es sich um ChatGPT von OpenAI.
Zusätzlich sind auch die .stl-Dateien der gedruckten Bauteile hier abgelegt und können in Form eines 3D-Modells betrachtet werden.
